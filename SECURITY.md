# Security Policy

## Supported versions

Only the latest release on npm (`@sahasbelbase/project-intelligence`) receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**.

Include the version, your platform, and steps to reproduce. You can expect an acknowledgement within 7 days and a fix or mitigation plan within 30 days.

## Scope

Areas that matter most: the installer (it writes into agent configuration files), the local MCP server, and the website server in `web/`.

Skills and councils for AI coding agents.

Project Intelligence is a local-first framework that gives AI coding agents skills, specialist agents, multi-persona councils and lifecycle gates. Every request goes to one orchestrator, which answers it, hands it to a specialist, or convenes a design, development or product council. Works with Claude Code, GitHub Copilot CLI, Antigravity and any MCP client.
